# Visores BIM

Área para visores BIM, prototipos e integraciones web o de escritorio. Cada proyecto debe indicar plataforma, tecnologías y versiones realmente utilizadas, formatos soportados, requisitos, instrucciones de ejecución y validaciones.

No se presupone un framework ni se añaden configuraciones de frontend hasta que exista un proyecto que las necesite.

## Subcategorías previstas

| Ruta futura | Finalidad |
| --- | --- |
| `01-visores-web/` | Aplicaciones para visualizar modelos BIM en navegador. |
| `02-visores-escritorio/` | Aplicaciones de visualización de escritorio. |
| `03-integraciones/` | Adaptadores entre visores, modelos y otros sistemas. |

Crea una ruta solo para un proyecto real. Cada visor o integración debe declarar sus formatos compatibles y conservar dentro de su proyecto las dependencias, configuración y pruebas que necesite.
