# Documentación

Guías, convenciones y decisiones que aplican a varias áreas del repositorio. La documentación específica de una herramienta debe vivir junto a esa herramienta; enlázala aquí solo cuando aporte contexto transversal.

## Subcategorías previstas

| Ruta futura | Finalidad |
| --- | --- |
| `01-guias/` | Guías generales de uso y mantenimiento del repositorio. |
| `02-convenciones/` | Convenciones compartidas de nombres, datos y documentación. |
| `03-decisiones/` | Decisiones de arquitectura y sus motivos. |

Crea una ruta solo cuando haya contenido real que lo justifique. La documentación de dependencias, configuración y pruebas de un proyecto debe permanecer con ese proyecto; evita duplicarla aquí.
