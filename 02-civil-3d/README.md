# Civil 3D

Área para automatizaciones y recursos de Autodesk Civil 3D. Documenta la versión de Civil 3D, el lenguaje o entorno de ejecución, requisitos y pasos de instalación, uso y validación de cada proyecto.

No se presupone una API o herramienta concreta.

## Subcategorías previstas

| Ruta futura | Finalidad |
| --- | --- |
| `01-scripts-api/` | Scripts y automatizaciones que usan las API de Civil 3D. |
| `02-dynamo-civil-3d/` | Grafos Dynamo ejecutados con Civil 3D como aplicación anfitriona. |
| `03-complementos/` | Complementos instalables para Civil 3D. |

Crea estas rutas solo cuando exista un proyecto real. Documenta y valida por separado sus versiones de Civil 3D/Dynamo, dependencias, configuración y pruebas. Los grafos Dynamo para Revit corresponden a `01-revit/`.
