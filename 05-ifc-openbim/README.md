# IFC y OpenBIM

Área para proyectos de intercambio y automatización basados en IFC y flujos OpenBIM. Por proyecto, documenta las versiones de esquema o herramientas probadas, formatos de entrada y salida, validaciones y requisitos.

Evita incluir modelos de clientes o datos sensibles sin autorización.

## Subcategorías previstas

| Ruta futura | Finalidad |
| --- | --- |
| `01-validacion-ifc/` | Comprobaciones de archivos y datos IFC. |
| `02-transformacion-ifc/` | Conversión, extracción y transformación de información IFC. |
| `03-interoperabilidad/` | Intercambio entre herramientas y otros flujos OpenBIM. |

Crea una ruta solo cuando haya un proyecto real. Documenta las versiones de esquema IFC y herramientas realmente verificadas; mantén dependencias, configuración, modelos de prueba autorizados y pruebas por proyecto.
