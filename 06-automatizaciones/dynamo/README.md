# Dynamo

Directorio de documentación preexistente para Dynamo. Los proyectos nuevos se clasifican según su aplicación anfitriona: Dynamo para Revit en `01-revit/03-dynamo-revit/` y Dynamo para Civil 3D en `02-civil-3d/02-dynamo-civil-3d/`. Crea esas rutas únicamente cuando exista un proyecto real.

No se presuponen paquetes, versiones ni grafos de ejemplo.

Para cada proyecto real, documenta la versión de Dynamo y de Revit o Civil 3D, los paquetes, las entradas y salidas, y los pasos de validación en su aplicación anfitriona. Mantén sus dependencias, configuración y pruebas junto al proyecto.
