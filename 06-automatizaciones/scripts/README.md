# Scripts generales

Utilidades pequeñas que no dependan de una plataforma BIM específica. Si un script pertenece a Revit, Dynamo, pyRevit, Civil 3D, QGIS, IFC o un visor, colócalo en el área correspondiente.

Documenta el propósito, versión de intérprete probada, argumentos, archivos que lee o escribe y forma de validarlo. Declara dependencias solo si son necesarias para el script.
